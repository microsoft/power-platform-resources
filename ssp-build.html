ALM release checklist

Prepare your solution for release

Use application lifecycle management (ALM) to move changes from development through test to production with versioned solutions, validation, and controlled deployment.

  1. 01 / PLAN

    Define the release path

    • Confirm development, test, and production environments and release owners.
    • Agree source control, solution boundaries, and approval gates.
    Open the enterprise-scale design journey →
  2. 02 / PACKAGE

    Version the solution

    • Check publishers, dependencies, environment variables, and connection references.
    • Commit source changes and prepare a versioned managed solution for downstream environments.
    Open Solution Packaging Guide →
  3. 03 / VALIDATE

    Check before promotion

    • Run solution checks and functional, security, and performance tests in a test environment.
    • Resolve blocking findings and record acceptance evidence and approval.
    Review your solution →
  4. 04 / DEPLOY

    Release and verify

    • Promote the validated version through a pipeline with target configuration and approvals.
    • Confirm recovery steps, run post-deployment checks, and monitor the release.
    Open Pipeline Setup Assistant →
